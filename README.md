# شرکت خدمات شهری شهرسازان
قالب اولیه وب‌سایت شرکتی چندصفحه‌ای، فارسی و راست‌چین.

## ساختار
- `index.html`: صفحه نخست
- `pages/`: صفحات درباره ما، خدمات، حوزه فعالیت و تماس
- `assets/css/`: استایل‌ها
- `assets/js/`: رفتارهای تعاملی
- `assets/fonts/`: فونت‌های فارسی محلی
- `assets/images/`: تصاویر و نشان‌های تصویری
